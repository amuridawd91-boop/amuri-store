#  Amuri Store

Amuri Store is a small e-commerce project that I am building while learning React.

I made this project because I wanted to practice React by building something a little more difficult than my previous project. I wanted to learn how to work with products, APIs, components, props, state, and a shopping cart.

This project is still part of my learning process, so I am adding features step by step as I learn new things.

##  About the Project

The idea is simple: users can see a list of products and add products to a shopping cart.

The products are coming from the DummyJSON API, so the products are loaded dynamically instead of being written manually in the code.

I am building this project step by step and trying to understand the code instead of just copying a complete project.

##  What I Have Built So Far

- Fetch products from an API

- Add a dark theme using CSS

While building this project, I am learning and practicing:

- Conditional rendering
- `.map()`

One thing I learned from this project is that state is very important in React.

For example, the cart is stored in state, and when I add or remove a product, React updates the state and the page updates automatically.

I also learned that I cannot just change the existing array directly. I need to create a new array when updating the state.

##  Project Structure

The main files in this project are:

- `App.jsx` - The main component. It handles the products, cart state, and most of the main functions.
- `ProductCard.jsx` - Displays each product and contains the Add to Cart button.
- `Cart.jsx` - Displays the products that have been added to the cart.
- `App.css` - Contains the styling for the application.
- `index.css` - Contains the general styling for the application.
- `main.jsx` - The entry point of the React application.
